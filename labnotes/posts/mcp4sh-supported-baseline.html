The supported MCP4SH baseline

MCP4SH should not be treated like a standard SimHub effects profile where each effect is simply a raw standalone formula.

The plugin works more like a telemetry-to-haptics codec. It normalizes, cleans, gates, routes, balances, and tensions signals before exposing the public outputs used by the supplied SimHub profile.

That matters because separated graphs, manually edited formulas, or heavily modified profiles can be useful for personal experimentation, but they are not the supported reference for determining whether MCP4SH is behaving correctly.

The supported reference is the current supplied MCP4SH plugin, profile, channel map, and Setup Assistant workflow. Once formulas are manually separated or interpreted in isolation, the result may no longer represent the intended full plugin behaviour.
