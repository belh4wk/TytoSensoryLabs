MCP4SH v1.1.11 field notes

MCP4SH v1.1.11 is mostly about making the current ST Haptics baseline cleaner, calmer, and more reliable across titles.

The main practical difference is not a new headline effect. It is the way the existing effects now separate under load: suspension impact behaviour is less likely to become a constant bed, Brake Feel and ABS/Lock are clearer, and Engine & Tyres has more readable articulation without changing the intended front/rear drivetrain balance.

This release also tightens the setup and release path: updated profile assets, initial layout preset groundwork, safer license input handling, unified TytoSensoryLabs local state storage, OneDrive Documents support, and the first public-facing TCR language.

In plain terms: this is intended to be a stronger, calmer baseline rather than a louder one.
